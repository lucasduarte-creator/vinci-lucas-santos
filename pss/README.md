# VINCI — Electric Vehicles

Landing page responsiva criada a partir dos materiais visuais do arquivo Figma `PROJETO-VINCI.fig`.

## Tecnologias
- HTML5 semântico
- CSS3 responsivo (desktop, tablet e celular)
- JavaScript puro para menu mobile, detalhes dos modelos e formulário demonstrativo

## Testar localmente
Abra `index.html` no navegador. Para uma experiência mais próxima de hospedagem, use a extensão Live Server do VS Code.

## Publicar no GitHub Pages
1. Crie um repositório público no GitHub e envie todos os arquivos desta pasta para a raiz do repositório.
2. No repositório, abra **Settings → Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**, selecione `main` e a pasta `/ (root)`, depois salve.
4. Aguarde a publicação e teste o endereço em uma janela anônima.

**Atenção ao requisito do professor:** a URL publicada precisa conter seu nome e sobrenome. Confira o endereço final antes de entregar no AVA. O formulário deste protótipo é demonstrativo e não envia dados para um servidor.
